# Регламент: от ТЗ до пакета на производство

## Этап 0. ТЗ → таблица параметров (без SolidWorks)
Из `01_input` составить в `02_cad/params.md`:
- габариты и управляющие параметры (L, B, H, шаг, толщины, профили);
- состав изделия: дерево сборки, для каждой детали — тип (**лист / труба / покупное / прочее**);
- что будет меняться в будущем (→ в переменные).
**Согласовать с заказчиком до моделирования.** Это то, что убирает «10 перерисовок».

## Этап 1. Каркас сборки (скелет)
- Сборка-верх `<КОД>_СБ.SLDASM`, в ней глобальные переменные из params.md.
- Скелетная деталь/эскиз-разметка (оси, контрольные плоскости) — все детали ссылаются на неё.
- Трубы: одна деталь-Weldment на узел (рама), профили из библиотеки, обрезка/торцы — инструментами Weldment.
- Лист: Sheet Metal с параметрами гиба из `10_LIBRARY/standards_company/` (K-фактор, радиус по толщине).

## Этап 2. Проверка модели (`sw-checker`)
Эскизы определены · нет ошибок перестроения · интерференции нет · развёртки строятся · свойства заполнены · масса посчитана.

## Этап 3. Чертежи
Шаблон из `10_LIBRARY/standards_company/`. Сборочный чертёж + спецификация, деталировка на нестандартные детали, развёртки на лист, таблица резов на трубы. Экспорт PDF в `03_drawings_pdf`.

## Этап 4. Экспорт на станки
- Лист → DXF 1:1, только контур + отверстия (+ линии гиба отдельным слоем, если нужно) → `04_dxf_laser`.
- Труба → каждая труба отдельным файлом STEP/IGES → `05_tube_3d` → TubesT.
- BOM (XLSX) → `06_bom`.

## Этап 5. Ревизия
Изменение = правка параметра/фичи в существующей модели → перестроение → повтор этапов 2–4 только для затронутых деталей. Номер ревизии в свойствах и имени пакета.

## Как Claude управляет SolidWorks
Варианты (выбрать в QUESTIONS.md):
- **A. API-автоматизация** — Python (`pywin32`) / VBA-макросы в `macros/`, Claude пишет и запускает их на этой машине.
- **B. Инструкции** — Claude выдаёт пошаговый план по дереву, вы кликаете.
- **C. Гибрид** — модель руками по плану, экспорт/проверка/свойства — макросами (рекомендуется для старта).
