1. Только после OK от `sw-checker`.
2. Шаблон и формат — из `10_LIBRARY/standards_company/`. Масштаб стандартный, виды: главный + необходимые, изометрия для сборки.
3. Размеры — импорт из модели (Model Items), затем чистка; не дублировать, базы как в технологии.
4. Сборка: позиции + спецификация из BOM. Лист: вид развёртки, направление гиба. Труба: длина, углы реза.
5. Основная надпись берётся из свойств файла — руками не вписывать.
6. Экспорт PDF → `03_drawings_pdf/<ОБОЗН>_<Наим>_rev<N>.pdf`.
