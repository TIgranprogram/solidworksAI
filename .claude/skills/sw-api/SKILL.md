1. Справочник вызовов — `docs/API_SOLIDWORKS.md`. Не угадывай сигнатуры: нет в справочнике → смотри API Help 2026 и допиши справочник.
2. Подключение и базовые функции — только через `macros/python/sw_connect.py`; новые общие функции добавляй туда.
3. Единицы API: метры и радианы. Переменные в Equations — мм (как в модели).
4. Перед пакетной операцией — проверь, что файл открыт без ошибок; после — ForceRebuild3 и проверка ошибок дерева.
5. Никогда не перезаписывай модель без копии: правка → SaveAs в ту же папку только после успешного перестроения.
6. Проверка связи: `python macros/python/sw_connect.py` — должен напечатать номер версии (34.x).
