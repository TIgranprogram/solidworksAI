---
name: sw-export-dxf
description: Экспорт развёрток листовых деталей в DXF 1:1 для лазерной/плазменной резки.
---
1. Каждая листовая деталь: Flat Pattern → Export to DXF (из детали, не из чертежа), масштаб 1:1.
2. Включать: внешний контур, отверстия; линии гиба/маркировку — по ответу Q11, отдельным слоем.
3. Без размеров, рамки, текста, сплайнов-артефактов; контуры замкнуты.
4. Имя: `<ОБОЗН>_<материал>_<толщина>mm_<N>шт.dxf` → `04_dxf_laser/`. Количество — из BOM.
5. Сверка: габарит DXF = габарит развёртки в модели.
