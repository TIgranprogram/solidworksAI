---
name: sw-model
description: Построение или правка 3D-модели детали/сборки в SolidWorks по параметрам. Используй при создании новой детали, сборки, рамы из труб или листовой детали.
---
1. Прочитай `docs/QUESTIONS.md` (ответы) и `02_cad/params.md` изделия. Нет params.md — сначала составь его и согласуй.
2. Проверь, существует ли файл детали. Существует → используй навык `sw-revision`, не создавай заново.
3. Тип детали: труба → Weldment, профиль из `10_LIBRARY/standards_company/`; лист → Sheet Metal с K-фактором из стандартов; иное → обычная твёрдотельная.
4. Порядок: глобальные переменные → скелет/опорный эскиз от начала координат → основные фичи → отверстия → фаски/скругления последними.
5. Все размеры — через переменные (`"L"`), эскизы полностью определены, фичи переименованы.
6. Заполни свойства: Обозначение, Наименование, Материал, Толщина/Профиль, Разработал.
7. Сохрани `02_cad/<ОБОЗН>_<Наим>.SLDPRT`, затем передай на проверку агенту `sw-checker`.
