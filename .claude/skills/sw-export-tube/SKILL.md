---
name: sw-export-tube
description: Подготовка и экспорт труб из Weldment в 3D (STEP/IGES) для BLM TubesT и трубореза.
---
1. Каждая труба — отдельное тело с профилем из библиотеки; Cut List обновлён, длины/углы в свойствах.
2. Сохранить каждое тело отдельным файлом (Save Bodies / Insert into New Part) — TubesT работает с одной трубой.
3. Экспорт в формат из Q3 (по умолчанию STEP AP214) → `05_tube_3d/<ОБОЗН>_<профиль>_L<длина>_<N>шт.step`.
4. Проверить: длина ≤ макс. станка, профиль из поддерживаемых, отверстия/пазы — реальные вырезы в теле.
