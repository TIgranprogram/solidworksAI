Разбор входящих: определи тип файла → перемести по таблице `10_LIBRARY/README.md` с правильным именем → запись в `_AI/inbox_log/<ГГГГ-ММ>.md` (файл, куда, почему).
Из каждого полезного файла извлеки знания в `_AI/knowledge/<тема>.md` (дата + путь-источник). Модель/изделие → строка в `_AI/analogs_index/INDEX.md`.
Поиск аналога: сначала INDEX.md, затем `10_LIBRARY/models_analogs` и `projects/`. Отвечай списком: путь, чем похож, что взять.
Неясный файл — не угадывай, оставь в 00_INBOX и спроси.
