# solidworksAI

**SolidWorks → полный пакет на производство одной цепочкой.**
Модель · чертежи PDF · DXF на лазер · STEP труб в TubesT · спецификация · рендеры · техописание · паспорт.

> Главный принцип: **модель строится один раз и дальше только правится.** Все размеры — переменные; поменяли цифру — всё пересобралось.

---

## 🚀 Старт на рабочем ПК (с SolidWorks)
```bash
git clone https://github.com/TIgranprogram/solidworksAI.git
pip install -r requirements.txt
python macros/python/check_setup.py
```
Все пункты `[OK]` → можно работать. Дальше: скажите Claude **«что дальше?»** — он доложит по `docs/ROADMAP.md`.

## 📁 Структура
| Папка | Для кого | Зачем |
|---|---|---|
| `00_INBOX/` | люди | кидать всё новое без сортировки |
| `10_LIBRARY/` | люди | справочная база (см. «Что загрузить») |
| `20_TEST/` | все | песочница |
| `_AI/` | агенты | их память: знания, индекс аналогов, уроки, шаблоны ТО/паспорта |
| `projects/` | все | изделия; `_TEMPLATE` → копировать |
| `docs/` | все | регламент, вопросы, API, дорожная карта |
| `macros/` | агенты | Python/VBA для SolidWorks |

Папки изделия: `01_input` `02_cad` `03_drawings_pdf` `04_dxf_laser` `05_tube_3d` `06_bom` `07_render` `08_docs_tech` `09_passport`

## 🤖 Агенты
| Агент | Делает |
|---|---|
| **librarian** | разбирает INBOX, ищет аналоги, ведёт память `_AI` |
| **sw-designer** | строит и правит модели |
| **sw-checker** | нормоконтроль перед выдачей |
| **doc-writer** | рендеры, техописание, паспорт |

Навыки: `sw-model` `sw-revision` `sw-drawings` `sw-export-dxf` `sw-export-tube` `sw-api` `sw-docs`
