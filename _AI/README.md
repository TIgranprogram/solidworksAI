# _AI — память агентов (люди сюда не пишут, только читают)
| Папка | Содержимое | Кто пишет |
|---|---|---|
| `knowledge/` | выжимки из библиотеки: правила, размеры, стандарты — по темам (`tube.md`, `sheet.md`, `drawings.md`, `machines.md`) | librarian |
| `analogs_index/` | `INDEX.md`: каталог изделий/деталей с параметрами и путями — поиск аналогов | librarian |
| `lessons/` | ошибки и найденные решения: «что пошло не так → как правильно» | все агенты |
| `inbox_log/` | журнал разбора входящих: что, куда, зачем | librarian |
| `templates_text/` | шаблоны текстов: ТО, паспорт, описание узлов | doc-writer |
Правила: одна тема — один файл; дополнять, не дублировать; каждая запись с датой и источником (путь к файлу).
