# 10_LIBRARY — справочная база (для людей)
| Папка | Что класть |
|---|---|
| `drawings_examples/` | эталонные чертежи «как надо» (PDF/SLDDRW) |
| `models_analogs/` | готовые модели прошлых изделий — аналоги для новых |
| `standards_company/` | шаблоны рамки/штампа, шаблоны деталей, свойства, K-факторы |
| `standards_gost/` | ГОСТ/ЕСКД, которые реально применяете |
| `materials_profiles/` | сортамент труб/листа, библиотека Weldment-профилей, материалы |
| `machines/` | паспорта станков: труборез, лазер, гибочник, ограничения |
| `passports_examples/` | образцы паспортов, ТО, инструкций изделий |
| `photos_references/` | фото, эскизы, референсы внешнего вида |
Имя файла: `<что>_<изделие/тема>_<дата ГГГГ-ММ-ДД>.<ext>`, без пробелов.
