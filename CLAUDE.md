# Правила работы (SolidWorks-проект)

Цель: модель → чертежи PDF → DXF для листа → 3D труб для TubesT. Подробно: `docs/WORKFLOW.md`.
Ответы заказчика на вопросы: `docs/QUESTIONS.md` — **они важнее любых умолчаний ниже.**

## Железные правила
1. **Не перерисовывать — править.** Перед любой правкой открыть существующую модель и изменить параметр/фичу. Новый файл — только для новой детали.
2. **Параметры наверху.** Все габариты изделия — в глобальных переменных сборки (`Equations`) или Design Table. В эскизах — ссылки на переменные, а не числа.
3. **Эскизы полностью определены** (чёрные). Привязка к началу координат и плоскостям, не к рёбрам временных фич.
4. **Дерево короткое и читаемое.** Фичи переименованы (`Ножка_труба`, `Отв_М8`), не `Вытяжка17`.
5. **Листовой металл — только инструментами Sheet Metal** (иначе не будет развёртки). Труба — только `Weldments` со стандартным профилем из `10_LIBRARY/standards_company/` (иначе TubesT не распознает).
6. **Одна деталь = один файл = одно обозначение.** Одинаковые детали — один файл, количество в BOM.
7. **Свойства файла заполняются сразу:** Обозначение, Наименование, Материал, Толщина/Профиль, Масса, Разработал.
8. **Чертежи и экспорт — только после проверки модели** (агент `sw-checker`).
9. **Имена файлов:** `<ОБОЗНАЧЕНИЕ>_<Наименование>.<ext>`, напр. `LV-001-03_Ножка.SLDPRT`. DXF: `<ОБОЗН>_<материал>_<толщина>mm_<кол-во>шт.dxf`.
10. **Любая правка = ревизия** (навык `sw-revision`): меняется модель → пересобираются PDF/DXF/STEP, старые в `_old/`.

## Навыки и агенты
- `.claude/skills/sw-model` — построение/правка модели
- `.claude/skills/sw-drawings` — чертежи
- `.claude/skills/sw-export-dxf` — развёртки DXF
- `.claude/skills/sw-export-tube` — трубы для TubesT
- `.claude/skills/sw-revision` — изменения без перерисовки
- агенты: `sw-designer` (строит), `sw-checker` (проверяет до выдачи)

## Папки и память
- Новое от людей — в `00_INBOX`; разбирает агент `librarian`. Справочники — `10_LIBRARY` (только читать и раскладывать).
- **Перед новым изделием — поиск аналога** в `_AI/analogs_index/INDEX.md` и `_AI/knowledge/`; переиспользовать, а не строить с нуля.
- Свои выводы агенты пишут только в `_AI/` (знания, уроки, журнал). Ошибка исправлена → запись в `_AI/lessons/`.
- Изделие считается готовым, когда есть все папки 01–09: модель, чертежи, DXF, STEP, BOM, рендеры, ТО, паспорт (агент `doc-writer`).
